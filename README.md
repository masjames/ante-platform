# ANTE Platform

Internal static website engine for KALANA-managed websites.

## Purpose

ANTE Platform is not sold directly. It is used internally by KALANA to build, migrate, host, and maintain client websites.

## MVP Focus

- Content Core
- Render Core
- Static-first output
- Free infrastructure first
- Frame Malang as flagship implementation

## First Target

Render a fast static version of Frame Malang with:

- home page
- articles
- categories
- membership/support page
- sponsor slots

## Suggested Stack

Start simple:

- TypeScript
- file-based content first
- static HTML output
- deployable to Cloudflare Pages, Vercel, Netlify, or GitHub Pages
